 ❌ Error Handling

  Common Errors

  | Error Message                                      | Meaning               | Solution                |
  |----------------------------------------------------|-----------------------|-------------------------|
  | Authentication required                            | No token provided     | Login first             |
  | Only regular users can activate vouchers           | Admin/cashier account | Use player account      |
  | PIN code system is not available                   | System disabled       | Contact admin to enable |
  | PIN code not found or does not belong to your shop | Invalid code          | Check code format       |
  | This PIN code has already been used                | Code used before      | Get new code            |
  | Cashier shift is not open                          | No active shift       | Contact support         |
  | Insufficient shop balance                          | Shop low on funds     | Contact support         |
  | Failed to activate PIN code                        | System error          | Check logs, retry       |

  Error Response Format

  {
    "error": "This PIN code has already been used"
  }
