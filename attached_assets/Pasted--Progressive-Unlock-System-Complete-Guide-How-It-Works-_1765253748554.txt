  🎡 Progressive Unlock System - Complete Guide

  How It Works

  Flow:
  1. New users start with only Wheel 1 unlocked
  2. To unlock Wheel 2, they must land on the "WH" prize on Wheel 1
  3. To unlock Wheel 3, they must land on the "WH" prize on Wheel 2
  4. Once all wheels are unlocked, landing on "WH" gives a bonus message

  Database Changes

  New Column Added:
  - Table: w_users
  - Column: unlocked_wheels (VARCHAR(20), default: '1')
  - Format: Comma-separated wheel numbers (e.g., "1,2,3")

  ---
  UI/App Integration Guide

  Step 1: Get Config
  const config = await fetch('/api/mobile/wheel-fortune/config', {
    headers: { 'Authorization': 'Bearer ' + token }
  }).then(r => r.json());

  // Show only unlocked wheels in UI
  const availableWheels = config.unlocked_wheels; // [1] or [1,2] or [1,2,3]
  const currentWheel = config.current_wheel;       // 1, 2, or 3

  // Display lock icons for locked wheels
  if (!availableWheels.includes(2)) {
    showLockIcon('wheel2');
  }

  Step 2: Spin Wheel
  const result = await fetch('/api/mobile/wheel-fortune/spin', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer ' + token,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ wheel: currentWheel })
  }).then(r => r.json());

  // Check if new wheel was unlocked
  if (result.wheel_unlocked) {
    showUnlockAnimation(result.wheel_unlocked);
    enableWheel(result.wheel_unlocked);
  }

  // Show prize/message
  showMessage(result.message);

  Admin Features

  Reset User's Wheels (via database):
  -- Reset to Wheel 1 only
  UPDATE w_users SET unlocked_wheels = '1' WHERE id = {user_id};

  -- Unlock all wheels
  UPDATE w_users SET unlocked_wheels = '1,2,3' WHERE id = {user_id};

  -- Unlock up to Wheel 2
  UPDATE w_users SET unlocked_wheels = '1,2' WHERE id = {user_id};
